# ROW Swimming Math

Goal time and race split calculator for ROW Swim Club swimmers and coaches.

**Live site:** https://<username>.github.io/<repo>/

## What this is

A single self-contained HTML file. No build step, no dependencies, no tracking.
Open `index.html` in any browser and it works.

It lives here rather than on rowswimming.ca because the club website runs on
SportsEngine Motion (TeamUnify), whose content sanitizer strips `<script>` tags
and does not accept `.html` uploads.

## Editing

Everything is in `index.html`: styles in the `<style>` block, logic in the
`<script>` block at the bottom. Commit to `main` and GitHub Pages redeploys
in about a minute.

## The math

Goal times, from any one best time:

| Step | Formula |
|---|---|
| 50 to 100 | `PB50 x 2 + 5` |
| 100 to 200 | `GOAL100 x 2 + 10` |
| 200 to 400 | `GOAL200 x 2 + 10 to 15` |
| 400 to 800 | `GOAL400 x 2 + 15 to 20` |
| 400 to 1500 | `GOAL400 x 4` |

Run in reverse from a 100 (`GOAL50 = (PB100 - 5) / 2`) or a 200
(`GOAL100 = (PB200 - 10) / 2`). The ladder is consistent in both directions.

Distances of 400 and up are freestyle. The 50, 100 and 200 math is the same in
every stroke.

Race splits, where `n` is the number of 50s:

```
opening 50 = (goal - drop x (n - 1) + kick) / n
every 50 after = opening + drop
final 50 (400 and up) = that minus the kick
```

Drop-off ceilings: 2.0s in a 100 and 3.0s in a 200 or longer for freestyle and
backstroke; 4.0s for breaststroke and butterfly. Closing kick is 1.0s, applied
to the 400, 800 and 1500 only.
